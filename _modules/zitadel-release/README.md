# zitadel-release

Installs the [Zitadel Helm chart](https://github.com/zitadel/zitadel-charts)
via `helm_release`, bridging the Terraform-managed encryption masterkey
(generated by `_modules/zitadel-secrets`) into a Kubernetes Secret the chart
references by name (`zitadel.masterkeySecretName`), since the chart cannot
accept the masterkey as a plain Helm value.

Modeled directly on `wp.lodge104.net`'s `_modules/helm-release` module, but
scoped to what Zitadel specifically needs instead of WordPress/RDS/S3
bridging.

All other Zitadel configuration (database connection, cache connection,
first-instance admin bootstrap, ingress annotations, TLS) is supplied via
the `values` list, composed in each environment's `terragrunt.hcl` from
`_common/zitadel.hcl`'s `base_values` plus environment-specific overrides --
same pattern as `wp.lodge104.net`'s `wordpress` module.

## Providers

`helm` and `kubernetes` providers must be generated by the including
`terragrunt.hcl` (see the `eks` and `wordpress` units in wp.lodge104.net for
the pattern); this module does not declare provider blocks itself.
